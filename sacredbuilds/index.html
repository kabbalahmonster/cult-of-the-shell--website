📖 Linux Build Instructions

Prerequisites

  • CMake 3.20+
  • g++ compiler
  • Linux development headers

Build Steps

  1. Extract: tar -xzf DoomBitcrusher-Linux-v1.0.tar.gz
  2. cd into folder, then:
    mkdir build && cd build
    cmake .. -DCMAKE_BUILD_TYPE=Release
    make -j$(nproc)
  3. Find outputs in DoomBitcrusher_artefacts/Release/
  4. Copy DoomBitcrusher.vst3 to ~/.vst3/

Quick Build Steps

  1. Extract the package to C:\dev\DoomBitcrusher\
